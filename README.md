# ILP3 — React Aula 11

Mini projeto da Aula 11 de Linguagem de Programação III: introdução ao React com Vite, JSX, componentes funcionais e props.

## Funcionalidades

- Componente reutilizável `Card` para os conceitos Virtual DOM, Componentes Funcionais e JSX.
- Componente `Aluno` com as props `nome` e `curso`.
- Exibição de três alunos diferentes no componente `App`.

## Executar

Requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

Abra o endereço local informado pelo Vite (normalmente `http://localhost:5173`).

## Validar build

```bash
npm run build
```

Projeto independente do módulo anterior de Vue.js (Aulas 1 a 10).
